## 来源与使用边界

| 字段 | 值 |
|---|---|
| 来源 | 用户声明：线上购买 |
| 允许用途 | 用户声明：可直接用于本项目并可公开展示 |
| 权利状态 | `user_asserted_permitted`；购买页/许可条款凭证待归档 |
| 学生个人数据 | 用户确认没有学生原始作答试卷；当前库存不得标记为真实学生证据 |
| Git 策略 | 原文件与完整转换文本不入 Git；Git 仅保存本登记、哈希/统计及项目原创或合成内容 |

转换时必须区分学生使用版本、教师/答案版本和解析版本，避免把答案键发送到学生端或混入诊断输入。购买材料可以作为内容、题型与测评结构来源；比赛 Demo 仍应优先选择已审校、来源清晰、答案完整且适用 Unit 1–4 的小规模子集。

答题卡和听力音频已明确排除出 MVP 题库、RAG、Prompt 与视觉 QA。原文件继续保存在 Git 忽略的私有目录，用于来源追溯；当前不永久删除，也不要求用户逐份核验。
